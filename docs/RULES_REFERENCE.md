# 건강분석 규칙 기준 (rules-2026.09-v1)

> ⚠️ **초안입니다.** 공개된 국내 진료지침·검진 판정 기준을 참고해 "건강관리 우선순위"용으로 만든 값이며,
> 실제 서비스 전 **의료 전문가의 검토가 필요**합니다. 이 결과는 진단이 아닙니다.
>
> 코드 기준: `src/domain/analysis/rules/thresholds.ts` — 값을 바꾸면 `RULES_VERSION`을 올립니다.

## 1. 공통 원칙

- 지표마다 **구간**(최적 OPTIMAL / 정상 NORMAL / 경계 BORDERLINE / 높음 ELEVATED)과 **관리 필요 점수**(0~100)를 매깁니다.
- 영역 점수 = 가장 나쁜 지표 60% + 평균 40% + (이상 지표 2개 이상이면 +10), 최대 100.
- 영역 상태
  - 검진 수치 영역: 높음 1개 이상 → 관리 필요, 경계 → 관심, 모두 최적 → 양호, 그 외 → 보통
  - 생활습관 영역: 높음 1개 이상 **또는 경계 2개 이상** → 관리 필요, 경계 1개 → 관심
  - 식습관: 문항이 많아, 경계·높음 합계가 3개 미만이면 관심으로 완화
- 관리 필요도(●): 양호 1 · 보통 2 · 관심 3 · 관리 필요 4 (점수 90 이상 5)
- **데이터 부족**: 필요한 입력의 50% 미만이고 이상 소견이 없을 때. 이상 소견이 있으면 입력이 적어도 알려줍니다.

## 3. 우선순위 TOP 3

```
priorityScore = (영역 점수 × 영역 가중치 + 연결 효과) × (0.7 + 0.3 × 입력 충족률)
```

- 대상: 관심 또는 관리 필요 영역
- 영역 가중치: 혈당 1.2 · 심혈관 1.15 · 대사/간/신장 1.0 · 체중/생활습관 0.95 · 운동 0.9 · 수면/식습관 0.85
- 연결 효과: 이 영역을 관리하면 함께 좋아질 수 있는 영역 중 관심·관리 필요인 영역 1개당 +3 (최대 +9)
- 동점이면 고정된 영역 순서로 정렬 → 같은 입력이면 같은 순서
- 대상이 3개 미만이면 보통 → 양호 순으로 "유지" 항목을 채움 (생활습관 영역 우선)
- 질병 확률·위험도는 계산하지 않습니다.

## 4. 복용약

- 약 이름은 분석에 사용하지 않습니다. 사용자가 적은 **복용 목적**에서 혈압·혈당·콜레스테롤 키워드만 찾아
  "현재 관리 중" 표시와 대사건강 요소 판정에만 사용합니다. 약에 대한 판단이나 권고는 하지 않습니다.

- (생체나이, §6) 혈압약·당뇨약·고지혈증약은 **성분·1정당 함량 + 하루 복용 알 수**를 선택 입력받아
  생체나이 보정에만 사용합니다. 분석 엔진(10개 영역 상태·우선순위)은 여전히 복용 목적 키워드만 사용합니다.

## 5. 의료 자문 시 검토 요청 항목

1. 각 임계값과 점수(특히 생활습관 문항의 구간)
2. 영역 가중치와 우선순위 공식
3. 흡연을 심혈관·생활습관 영역에 중복 반영하는 방식
4. 연령별 기준 조정 필요 여부 (예: 고령자의 eGFR, 수면시간)
5. (생체나이) 성별·연령대별 기준 평균표, 표준편차 1당 환산 나이, 약효 평균값, 대사증후군 도달 시점 추정 방식

### 6.2 환산

1. `rules/reference.ts`: 성별·연령별 평균과 표준편차 곡선 (사이는 선형 보간, 중성지방·간효소는 로그 척도).
   - **NHIS (현재 적용)**: 국민건강보험공단 **한국인 참조표준**(공공데이터포털 xlsx)에서 만든 2세 간격 연령대별 값
     (`nhis-reference.generated.ts`, §6.5) — 수축기·이완기 혈압, 공복혈당, 총·HDL·LDL 콜레스테롤, 중성지방,
     허리둘레, 혈색소, eGFR(혈청크레아티닌 표에서 환산). 성별마다 4개 연령대 이상 있을 때 사용.
   - **DRAFT**: 참조표준이 없는 지표(**AST·ALT·γ-GTP·당화혈색소**)는 KNHANES·공단 통계연보 요약값 기반 10세 간격 초안.
   - 참조표준 파일에 기준년도 표기가 없어 버전은 `bioage-nhisref-v1` — 기준년도를 확인하면 `--year`로 다시 생성.
2. 지표별 `z = (내 값 − 또래 평균) / 표준편차` → `나이 차이 = z × yearsPerSd(4~7세)`,
   나쁜 방향 최대 +15세, 좋은 방향은 지표별 2~6세까지만.
3. 영역 나이 차이 = 입력된 지표의 가중 평균 (−10 ~ +20세). 입력 가중치 합이 기준 미만이면 "입력 부족".
4. 종합 생체나이 = 대사증후군 나이를 뺀 계산 가능 영역의 평균.

### 6.3 복용약 보정

- 복합제는 `src/domain/medication/catalog.ts`에서 단일 성분으로 나누고, `함량 × 하루 알 수`로 성분별 하루 용량을 합산.
- 표준 용량 대비 효과: `1 + k·log2(용량/표준용량)` (0.4 ~ 1+2k). 혈압약 k=0.22 [Law 2003/2009].
- 혈압: 계열별 표준용량 효과(수축기/이완기 mmHg)를 더함 (동일 계열은 한 번, 용량만 합산).
- 혈당: 계열별 HbA1c·공복혈당 감소, 병용은 효과 큰 순서로 1, 0.8, 0.65, 0.5 가중.
  측정 HbA1c가 정상에 가까울수록 효과를 작게 봄 (6.0% → 50%, 8.0% 이상 → 100%).
- 지질: 스타틴은 성분·용량별 LDL 감소율 표, 에제티미브·피브레이트·오메가-3는 비율; 병용은 `1 − Π(1 − r)`.
- "약을 먹지 않았다면" 추정값 = 측정값 + 감소량 (지질은 측정값 ÷ (1 − 감소율)) → 같은 방식으로 나이 환산.
  예: 당뇨나이 +1세 + 메트포르민 → 약이 낮춰 준 평균 범위를 되돌려 +2세 이상으로 보정.
- 성분·함량을 모르면 보정하지 않고 "보정 못함"으로 안내 (대사증후군 요소는 약 복용으로 해당 처리).
- 주사제(인슐린·GLP-1)와 목록에 없는 약은 보정하지 않습니다.

### 6.4 대사증후군 판정 기준 도달 시점 추정

- 요소 기준: 허리둘레 남 90 / 여 85cm, 혈압 130/85mmHg, 공복혈당 100mg/dL, 중성지방 150mg/dL, HDL 남 40 / 여 50mg/dL 미만.
  혈압약·당뇨약 복용 시 해당 요소, 고지혈증약 복용 시 중성지방 요소를 해당으로 봄 (분석 엔진과 동일).
- 약 보정 추정값에서 시작해 해마다 각 요소를 **대사증후군 나이 위치의 성별 평균 곡선 기울기**만큼 악화
  (코호트의 성인 평균 연간 변화보다 느리지 않게), 진행 속도 `pace = 1 + (대사증후군 나이 − 실제 나이)/20` (0.5~2배).
- 3번째 요소가 기준에 닿는 해 = 도달 추정 시점 (최대 30년, 90세까지). 이미 3개 이상이면 "현재 해당".
- 생활습관이 그대로라는 가정의 추정이며, 확률·진단 표현은 쓰지 않습니다.

### 6.5 기준표를 공단 최신 통계로 갱신하기

`npm run bioage:reference -- <파일…>` 로 `src/domain/bio-age/rules/nhis-reference.generated.ts`를 다시 만듭니다.
원자료는 `data/nhis/`에 두고 커밋하지 않습니다 (`.gitignore`). 실행 후 `npm run check` → 커밋 → 재분석한 결과부터 적용.

**A. 한국인 참조표준 xlsx (현재 사용)** — 공공데이터포털 "국민건강보험공단\_한국인 ○○ 참조표준"
(혈압·혈당·총콜레스테롤·중성지방·HDL·LDL·허리둘레·혈색소·혈청크레아티닌)을 한꺼번에 지정. 기준년도는 `--year 2021`처럼 지정.

- 전국 행 사용. 전국 행이 없는 표(허리둘레)는 시·도 행을 측정 수로 가중 평균
- 유병자·약복용자(혈압은 고혈압약 복용자) **포함/제외** 구분이 있으면 **제외**(미치료 또래)를 사용 —
  약 복용자는 "약을 먹지 않았다면" 수치로 비교하므로 기준도 미치료 집단
- 평균 = 측정값(중성지방은 50분위수), 퍼짐 = (75분위수 − 25분위수)/1.349 (중성지방은 로그 척도)
- eGFR = 크레아티닌 평균·표준편차를 연령대 중앙 나이의 CKD-EPI 2021로 환산
- 체질량지수 표는 생체나이에 쓰지 않아 건너뜀. "분포(95%) 하한·상한" 열은 일부 표(LDL)에서 성별 간 값이 같아 사용하지 않음

**B. 건강검진정보 원자료 CSV** — "국민건강보험공단\_건강검진정보"(수검자 100만 명 표본)

- EUC-KR/UTF-8 자동 인식, 연도별 열 이름 차이 흡수, 성별·5세 연령대별 허용 범위 밖 값 제외 → 양 끝 0.5% 절사 →
  평균·표준편차(로그 척도는 기하평균·기하표준편차), 표본 100명 미만 연령대 제외 (`--min-n`)
- 원자료 평균에는 약 복용자도 포함됩니다 (원자료에 복용 정보 없음).
